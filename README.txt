FORMA — статический SEO-сайт

1. Загрузите содержимое папки static-site в корень public_html.
2. Укажите реальные идентификаторы аналитики в assets/analytics-config.js.
3. Если используется собственный домен, замените канонический адрес в HTML, sitemap.xml и robots.txt.
4. На Apache сохраните .htaccess; на Cloudflare Pages сохраните _redirects и _headers.
5. Подробности изменений находятся в SEO-OTCHET.md.
